# Lab Notebook

The public, dated audit trail of the programme's process — in effect a rich commit history.
Entries are largely generated, then annotated by Noah, and carry the mistakes and abandoned
directions deliberately.

Distinct from `docs/research/`, which is the **evidence** layer: a research document is a
piece of work, a notebook entry is the narrative of work happening. An entry may cite a
research document; they are not the same artifact.

## Layout

`YYYY-MM-DD-short-slug.md`, one file per entry, flat. Dates are the entry's date, not the
date of whatever it describes.

## Format

**Not yet decided** — [#11](https://github.com/NGL321/mosaic/issues/11) owns it, and this
file will be replaced by its answer. That ticket has to settle what triggers generation, how
generated and annotated content are made visually distinct, how an entry cites a private
Transcript Archive session, and what keeps the volume down. Writing a format here first
would be the revision this directory exists to avoid.

What is already fixed and constrains #11:

- Entries cite Transcript Archive sessions **by sha256, through an `Index` manifest** — the
  archive is private, so an entry references a session it cannot link to
  ([#3](https://github.com/NGL321/mosaic/issues/3)).
- Provenance Tiers appear as badges — `⟦T3 · #31⟧` — with the debt issue named
  ([#5](https://github.com/NGL321/mosaic/issues/5); see [`../curriculum/README.md`](../curriculum/README.md)).
- The Weekly Reflection is written against the **annotated** set, and is deliberately not
  generated from the notebook. It lives in Drive, not here.

## Nothing here yet

By design. The first entry should be generated by whatever mechanism #11 settles on, so that
the mechanism is exercised rather than retrofitted to a hand-written example.
